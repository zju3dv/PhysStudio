# Pretrained assets

Download only the models needed for your demos. Assets stay in `data/`, which is
excluded from Git. Set `PHYSSTUDIO_DATA_ROOT` to use another storage location.

| Asset | Source and download | Used by |
| :--- | :--- | :--- |
| Playground | [FieryGS](https://github.com/PKU-VCL-Geometry/FieryGS#data) · [archive](https://drive.google.com/file/d/1NFXzr0YU3q1_ezjWVEgTmd-R8JX4J0lL/view) | Rain, snow |
| Firewoods | [FieryGS](https://github.com/PKU-VCL-Geometry/FieryGS#data) · [archive](https://drive.google.com/file/d/1EMWrcSLbeLjTWyGUh_cThYGvrrmMrvC0/view) | Rain, snow |
| Train | [Voxel51 model](https://huggingface.co/datasets/Voxel51/gaussian_splatting/tree/main/FO_dataset/train) · [Graphdeco cameras](https://repo-sam.inria.fr/fungraph/3d-gaussian-splatting/datasets/pretrained/models.zip) | Rain, snow |
| Bread | [PhysGaussian](https://github.com/XPandora/PhysGaussian) · [archive](https://drive.google.com/file/d/1e2_9OxfVtLSJTKl_y3TPaYQGjnvr3koT/view) | Splashing, locomotion, magnetism |
| Wolf | [PhysGaussian](https://github.com/XPandora/PhysGaussian) · [archive](https://drive.google.com/file/d/1FhB_1LFaC2ax71gbySn6hVR88_IiK0eU/view) | Splashing, locomotion, magnetism |
| Vase | [PhysGaussian](https://github.com/XPandora/PhysGaussian) · [archive](https://drive.google.com/file/d/1AZh-JCNTwq9Za0rxFpDEBk-9tN6o_izs/view) | Locomotion |

```bash
python -m physstudio fetch playground
python -m physstudio fetch firewoods
python -m physstudio fetch train
python -m physstudio fetch bread
python -m physstudio fetch wolf
python -m physstudio fetch vasedeck
# Or download all six:
python -m physstudio fetch all
```

The downloaders select PLYs, camera files, and configuration from the source
archives using HTTP range requests, verify ZIP CRCs, and record SHA256 hashes.
Train uses the Voxel51 Gaussian model with the Graphdeco camera set.
The locomotion pipeline derives its simulation cage and Gaussian bindings locally.

Expected layout after downloading and preparing the assets:

```text
data/
  rainy_gs/fierygs/{Playground,firewoods_sand_dark}/
  rainy_gs/voxel51/train/
  gaussian_splashing/{bread,wolf,vasedeck}/
  enlivening_gs/{bread,wolf,vasedeck}/  # Generated by the locomotion asset adapter
```

Downloaded models and source data retain their upstream licenses and attribution.
