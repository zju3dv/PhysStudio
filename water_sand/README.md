# Water + Sand · 3D LBM–MPM

Water + Sand combines [Volume-Preserving LBM-MPM Coupling for Air-Water-Sand Mixtures](https://lwkobe.github.io/papers/XWYDL2026/) with Gaussian rendering for 3D sandcastle erosion, sedimentation, and dam overtopping.

## Run

After [installation](../INSTALL.md), run any of the procedural scenes:

```bash
python -m physstudio run water_sand castle --gpu 0
python -m physstudio run water_sand sediment --gpu 0
python -m physstudio run water_sand breach --gpu 0
```

Each preset simulates and renders 180 frames at 1280 × 800, producing a
six-second video with a 62-degree camera orbit. All geometry is generated by
code. The default output is `outputs/water_sand/<scene>/`; its `showcase/`
folder contains the video, preview page, and numerical audit.

A short end-to-end check:

```bash
python -m physstudio run water_sand castle --frames 2 --width 320 \
  --output outputs/water_sand/check_castle --gpu 0
```

Use `--output` to choose a fresh run directory and `--dry-run` to inspect the
launcher's commands. Run all three scenes through the native harness:

```bash
CUDA_VISIBLE_DEVICES=0 python -m water_sand.demo \
  --output outputs/water_sand/all_scenes
```

| Scene | Sand particles | Young modulus | Cohesion scale | Physical duration |
| :--- | ---: | ---: | ---: | ---: |
| Sandcastle | 499,718 | 500 kPa | 0.08 | 2.898 s |
| Sedimentation | 106,577 | 80 kPa | 0.002 | 2.898 s |
| Sand dam | 630,882 | 140 kPa | 0.01 | 2.956 s |

All presets use a 128 × 84 × 75 grid with 2.95 cm spacing, two material points
per cell axis, and frictional container contact with coefficient 0.75. The
colored sediment aggregates share the same constitutive material.

## Simulation and rendering

- D3Q27 central-moment LBM evolves air and water, with conservative D3Q7 pore-water transport.
- Quadratic APIC MPM evolves sand with Hencky elasticity, Drucker–Prager plasticity, and hardening.
- Porosity, buoyancy, paired implicit drag, absorption, and saturation-dependent cohesion couple the phases.
- Physical output intervals, settling duration, drag length, and absorption rate stay fixed when refining the grid.
- Gaussian surface layers and deterministic 0.9–1.8 mm visual grains follow the simulated material. Dilute points remain visible as grain clusters; wet shading and residual suspension accompany refractive water.

MPM resolves the granular continuum; the Gaussian grains provide material-attached
visual detail. Cached positions use lattice coordinates, with
`world = (positions - 3) * dx`. Multiply cached velocities by `velocity_scale`
for metres per second. `deformation` stores the elastic deformation gradient.

## Customize and replay

`demo.py` contains the scene presets. `run.py` exposes material and resolution
controls, including `--young`, `--cohesion`, `--resolution`, `--frame-dt`,
`--settle-seconds`, `--drag-reference-dx`, and `--absorption-per-second`.
`--frame-dt` takes precedence over `--steps-per-frame`.

Render a saved trajectory with different appearance or camera settings:

```bash
CUDA_VISIBLE_DEVICES=0 python -m water_sand.render_granular \
  --input outputs/water_sand/castle/simulation \
  --output outputs/water_sand/castle_close \
  --camera close --frames 0 60 179 --grains 20 --suspension .10
```

`--grains` controls visual samples per exposed material point, `--sigma`
controls surface filtering, and `--suspension` weights residual suspended-sand
extinction. Their defaults are 20, 1.4 fine-grid cells, and 0.10.
`--diagnostics` also saves water normals, coverage, thickness, and sand buffers.
The harness supports `--quality legacy` for the original grid and surface renderer.

Simulation folders contain `config.json`, `initial.npz`, `states/`,
`audit.json`, and `complete.json`. Render folders contain `demo.mp4`, PNGs,
frame/camera records, and renderer settings. `report.py` checks correspondence,
finite states, conservation, covariance validity, and video decoding before
building the gallery. `compare.py` creates matched-camera rendering and
simulation controls.

## Checks and references

```bash
CUDA_VISIBLE_DEVICES=0 python -m water_sand.validate --output outputs/water_sand/physics.json
CUDA_VISIBLE_DEVICES=0 python -m water_sand.validate_resolution --output outputs/water_sand/resolution.json
CUDA_VISIBLE_DEVICES=0 python -m water_sand.validate_grains \
  --input outputs/water_sand/castle/simulation \
  --output outputs/water_sand/grains.json
```

Checks cover lattice moments, porous equilibrium, free fall, coupled water
accounting, drag across resolutions, and grain attachment. The full demo
trajectories have maximum relative water errors below 4.72e-6 and sand mass
errors below 5.47e-8.

The [released 2D code](https://github.com/DacianShaw/LBM-MPM-Air-Water-Sand)
provides the constitutive and coupling reference; [OpenHOMELBM](https://github.com/kuiwuchn/OpenHOMELBM)
provides the 3D Warp LBM organization reference. See the [MIT notice](LICENSE.reference)
and [pinned source revisions](references/sources.json).
